# FactoryForge · 3D 工厂编辑器

基于 Three.js 的浏览器端 3D 工厂布局编辑器，纯静态文件，无需构建。内置 **造船厂 Demo**、通用工厂 Demo 和 49 种程序化建模素材。

## 运行

```bash
python3 -m http.server 8000   # 然后访问 http://localhost:8000
```
需能访问 `cdn.jsdelivr.net`（加载 three@0.160）。也可直接用 GitHub Pages 托管仓库根目录。

## 功能
- **素材库**：8 大类 49 种素材（生产设备、起重设备、车辆、仓储、能源管线、建筑、船厂专用、人员标识），自动渲染缩略图，支持搜索、点击添加、拖拽放置到地面
- **编辑**：移动 / 旋转 / 缩放 gizmo、局部/世界坐标、网格吸附、属性面板精确输入、改色与色板、贴地
- **多选**：Shift 点击、Ctrl+A；整体变换、对齐 / 均分、成组 / 解组
- **场景大纲**：物体列表、显示/隐藏、锁定（锁定物体不可在视口中误选，如水域）
- **撤销 / 重做**、保存到浏览器、导入导出 JSON、截图 PNG、导入 .glb/.gltf 模型
- **视图**：透视 / 俯视平面图 / 正视 / 侧视、聚焦选中（F）
- **场景设置**：场地尺寸、地面/背景色、太阳强度与方位、阴影 / 网格 / 雾效
- **动画**：龙门吊小车与吊钩、门机回转变幅、塔吊、行车、冲压机、切割机、焊接火花、传送带、水面波浪、拖船摇摆、冷却塔蒸汽等

按 `?` 查看全部快捷键。

## 目录
```
index.html        页面布局
css/style.css     样式
js/main.js        编辑器核心（选择、变换、历史、导入导出、界面）
js/assets.js      素材注册表与程序化建模
js/scenes.js      演示场景（造船厂 / 通用工厂 / 空白）
```

新增素材：在 `js/assets.js` 中编写 `buildXxx(color)` 并注册到 `ASSETS`。
